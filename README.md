# Electromagnetism Breaking Simultation

This project models the magnetic field generated by a solenoid and simulates the motion of a magnet falling through it. Using the Biot–Savart law and numerical methods like the Runge-Kutta 4th order method, the simulation visualizes how electromagnetic forces interact with the magnet’s motion, resulting in a braking effect. The project includes 2D/3D field plots, trajectory comparisons, and an animation demonstrating the phenomenon.
